# NFT-MARKETPLACE
A full-stack decentralized NFT Marketplace built using Next.js, Solidity, Hardhat, and Pinata, deployed on the Holesky testnet.  🧩 Features: • Mint, upload, and trade NFTs (images, videos, audio, or 3D models) • Secure wallet connection through MetaMask • Dynamic NFT listings and collections with royalty support.
